# UberControl

UberControl é um aplicativo web de controle financeiro para motoristas, criado para registrar diárias, organizar custos mensais e acompanhar o resultado do mês de forma simples e prática.

## Acesso

https://ubercontrol.vercel.app/

## Instruções de uso

### Criar conta
1. Clique em **Criar conta**
2. Informe nome, e-mail e senha
3. Finalize o cadastro

### Fazer login
1. Clique em **Entrar**
2. Digite e-mail e senha
3. Após o login, o acesso ao painel será liberado

### Navegação
O aplicativo está dividido em:

- **Dashboard**
- **Lançamentos**
- **Custos**
- **Gráficos**
- **Perfil**

### Lançamentos
Na área de **Lançamentos**, informe:

- data
- ganho bruto
- km rodado
- preço do combustível
- consumo médio
- custos extras

Depois clique em **Salvar lançamento**.

O sistema calcula automaticamente:

- custo de combustível
- custo total
- lucro da diária

Também é possível **editar** ou **excluir** lançamentos já cadastrados.

### Custos mensais
Na área de **Custos**, registre os custos fixos do mês, como:

- financiamento
- seguro
- IPVA
- manutenção
- celular / internet
- lavagem
- outros custos

Depois clique em **Salvar custos**.

### Dashboard
Na área de **Dashboard**, o aplicativo mostra:

- receita do mês
- custos variáveis
- custos fixos
- lucro líquido
- média líquida por dia

### Gráficos
Na área de **Gráficos**, é possível visualizar o desempenho do mês de forma visual.

### Perfil
Na área de **Perfil**, o usuário pode visualizar os dados da conta e sair do aplicativo.

## Observações

- cada usuário acessa apenas os próprios dados
- os lançamentos e custos ficam vinculados à conta autenticada
- o resultado do dashboard depende dos dados registrados no mês selecionado
